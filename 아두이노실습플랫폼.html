📌 미션 1: 스위치 한 개로 LED 껐다 켜기 (디지털 입출력)
🛠️ [필수 실습 소자 안내]
• 아두이노 우노보드 1개, 브레드보드 1개
• LED 1개 (애노드는 저항을 거쳐 13번 핀에 연결, 캐소드는 GND)
• 푸시 버튼(스위치) 1개 (2번 핀 연결, 내부 풀업 사용)
• 220Ω 저항 1개 (LED 보호용)

📖 [1] 코드 개념 및 주석 해설 먼저 읽기

const int btnPin = 2; // 2번 핀을 스위치 입력 핀으로 사용하겠다
const int ledPin = 13; // 13번 핀을 내장 LED 출력 핀으로 사용하겠다

void setup() {
  pinMode(btnPin, [ 빈칸: 모드 설정 ]); // 버튼 핀을 내부 풀업 저항 모드로 설정하겠다
  pinMode(ledPin, OUTPUT); // LED 핀을 출력 모드로 설정하겠다
}

void loop() {
  int state = digitalRead(btnPin); // 버튼의 눌림 상태(HIGH/LOW)를 읽어오겠다
  if (state == LOW) {
    digitalWrite(ledPin, [ 빈칸: LED 상태 ]); // 버튼이 눌렸으므로 LED를 켜겠다
  } else {
    digitalWrite(ledPin, LOW); // 버튼을 뗐으므로 LED를 끄겠다
  }
}
💡 개념 힌트: 버튼이 안 눌릴 때 HIGH, 눌릴 때 LOW가 되도록 내부 저항을 켜는 모드와 출력에 전원을 공급하는 상태를 생각해보세요.
🔑 정답 힌트: 첫 번째 빈칸은 INPUT_PULLUP, 두 번째 빈칸은 HIGH 입니다.

📌 미션 10: [실생활 응용] 초음파 센서를 이용한 자동문 만들기
🛠️ [필수 실습 소자 안내]
• 초음파 센서 (HC-SR04): Trig 핀(7번), Echo 핀(6번)
• 문 열림 표시 LED (9번 핀) + 220Ω 저항 1개

📖 [1] 코드 개념 및 주석 해설 먼저 읽기

const int trigPin = 7; const int echoPin = 6; const int doorPin = 9; // 초음파 및 문 핀 설정

void setup() {
  pinMode(trigPin, [ 빈칸: 출력 설정 ]);
  pinMode(echoPin, [ 빈칸: 입력 설정 ]);
  pinMode(doorPin, OUTPUT);
}

void loop() {
  digitalWrite(trigPin, LOW); delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  long duration = pulseIn(echoPin, HIGH);
  long distance = duration * 0.034 / 2; // 거리(cm) 계산
  if (distance < 20) {
    digitalWrite(doorPin, HIGH); // 20cm 이내면 문 열림(LED 켜기)
  } else {
    digitalWrite(doorPin, LOW);
  }
}
